# Reference Assets & Copyright Guidelines

This directory (`public/assets/references/`) is strictly reserved for **non-production reference materials**, visual inspiration, mood boards, and assets that require formal rights clearance prior to public distribution.

## Guidelines
1. **Non-Production Status**: Files in this directory are never bundled directly into the public production build for live commercial deployment without verified licensing.
2. **Official Character Assets**: Official Sanrio characters (such as Hello Kitty, My Melody, Kuromi, Cinnamoroll) are registered trademarks of Sanrio Co., Ltd. For official hackathons or partner events, official brand assets provided by Sanrio/partners should replace the architectural placeholders in `/public/assets/characters/`.
3. **Custom Vector Illustrations**: All vectors in `/public/assets/decorations/`, `/public/assets/environments/`, `/public/assets/stickers/`, and `/public/assets/textures/` are custom original SVG illustrations inspired by kawaii geometry and open design motifs.
