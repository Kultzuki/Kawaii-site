# Hack The Future 2026

The official website for **Hack The Future: Hello Kitty 2026**, a national-level hackathon organized by the Department of CSE at Tula's University, Dehradun, in association with the Tula's ACM Student Chapter.

## Event

- **Format:** Online PPT and idea synopsis round followed by a 36-hour in-person campus finale
- **Dates:** September 25-26, 2026
- **Location:** Tula's University Campus, Dhoolkot, Dehradun, Uttarakhand
- **Teams:** 2-4 members
- **Registration:** INR 500 per participant, including meals and stay for the campus finale
- **Prize pool:** INR 7 Lakh

## Tech Stack

- Astro 5
- React 19
- TypeScript
- GSAP
- Lenis

## Getting Started

Install dependencies:

```bash
npm install
```

Start the local development server:

```bash
npm run dev
```

The site is available at `http://localhost:4321` by default.

## Scripts

| Command | Description |
| --- | --- |
| `npm run dev` | Start the development server |
| `npm run build` | Type-check and build the production site |
| `npm run preview` | Preview the production build locally |
| `npm run check` | Run Astro type and diagnostic checks |

## Project Structure

- `src/components/` - Astro and React UI components
- `src/data/` - Event, schedule, track, prize, and FAQ content
- `src/animations/` - GSAP, scroll, reveal, and interaction behavior
- `src/styles/` - Global styles, tokens, layout, and component styles
- `public/` - Static images, illustrations, icons, videos, and textures
